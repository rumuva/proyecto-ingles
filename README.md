# Proyecto Inglés

Portal de cursos en GitHub Pages. El primer curso se encuentra en `cursos/a1-50h/`.

## Añadir otro curso

1. Crea una carpeta propia bajo `cursos/` y coloca dentro el `index.html` y sus recursos.
2. Añade una tarjeta en la sección «Cursos disponibles» del `index.html` del portal con un enlace relativo hacia esa carpeta.
3. Abre el curso y confirma que cargan los audios, las imágenes y las actividades antes de compartirlo.

El repositorio contiene la versión para alumnado. Guarda la documentación docente en un espacio privado.
